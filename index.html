Build and export Programs or Presets from the main SabaySaBeat tool, then Import the downloaded .json file(s) here. Tap ▶ Go Live on any imported program to connect it to your MIDI pads and start playing — it applies the program's first preset immediately, and if it has more than one, cycles through them automatically at its saved interval. Nothing here can be edited; open the main tool on a computer to build or change a program, then re-export and re-import it. Imported programs are saved on this device so you won't need to re-import them next time. This player skips the custom label font to keep it lightweight — everything else, including Video Overlay, plays back faithfully (pad colors, notes, Duration, Heat Intensity, Neighbor Splash, Energy Pulse, Combo Rainbow, Re-Grid, Riso Print, Grain). If a program uses Video Overlay, the video/GIF itself has to be embedded in the exported file for it to show up here — export it again from the main tool if a program's video isn't appearing. While live, the gear icon in the bottom-right fades out after 3 seconds so it doesn't sit over the grid — tap anywhere on screen to bring it back.
